# SUPPORT

Getting Support for rw_blueprint

## How to Get Help

We appreciate your interest in rw_blueprint! Here's how to get help:

### For General Questions
- Read the [Documentation](README.md) first
- Check [existing issues](https://github.com/RapidWebs-Enterprise/rw_blueprint/issues) for similar questions
- Ask in [Discussions](https://github.com/RapidWebs-Enterprise/rw_blueprint/discussions) if available

### For Bug Reports
Please create a new issue with the following template:

```markdown
**Bug Description**
A clear and concise description of what the bug is.

**To Reproduce**
Steps to reproduce the behavior:
1. Go to '...'
2. Click on '....'
3. Scroll down to '....'
4. See error

**Expected Behavior**
A clear and concise description of what you expected to happen.

**Screenshots**
If applicable, add screenshots to help explain your problem.

**Environment:**
- OS: [e.g. Ubuntu 22.04]
- Version: [e.g. 0.2.0]
- Python version: [e.g. 3.11]
- Topology: [link or paste relevant section]

**Additional Context**
Add any other context about the problem here.
```

### For Feature Requests
Use the feature request template or describe your use case in a new issue.

### For Security Issues
**DO NOT** create a public issue. Email security@rapidwebs.org instead.
