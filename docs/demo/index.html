Core CLI Commands

Core Capabilities

Everything you need to manage infrastructure as code with confidence.

📋

Validate

Check topology YAML against a strict Pydantic schema with comprehensive error reporting.

⚡

Generate

Produce quadlet containers, Incus profiles, Mermaid diagrams, and documentation from topology.

🔍

Probe

Run read-only infrastructure probes (ports, Incus, podman, DNS, Tailscale) across multiple nodes.

📊

Reconcile

Three-way drift classification: missing, extra, and mismatched entities with severity levels.

🚀

Deploy

Execute deployment plans with dependency ordering, health checks, and automatic rollback.

🖼️

Image Lifecycle

Build, pull, push, inspect, and prune container images with security validation.

CLI Reference

Powerful commands for infrastructure management.

# Validate a topology file rw-blueprint validate topology.yaml # Output example: # Valid topology 'rapidwebs-rwdn' (7 nodes, 11 services).
# Generate all artifacts rw-blueprint generate topology.yaml --output docs/generated/ # Generates: # - docs/generated/quadlet/*.container # - docs/generated/diagrams/architecture.mmd # - docs/generated/docs/topology.md
# Run probes on multiple nodes rw-blueprint probe --nodes srv1,infra,enterprise,dev --output docs/live.json # Run specific probes rw-blueprint probe --probes incus,podman,port --nodes infra
# Preview deployment (dry-run) rw-blueprint deploy topology.yaml --node infra --dry-run # Deploy with auto-rollback on health check failure rw-blueprint deploy topology.yaml --node infra # Deploy specific services rw-blueprint deploy topology.yaml --node infra --services honcho-api,caddy # Force deploy (skip confirmation + auto-rollback) rw-blueprint deploy topology.yaml --node infra --force
# List images on node rw-blueprint image list --node infra # Build image from source rw-blueprint image build honcho-api --source /home/sysop/honcho --node infra # Pull from registry rw-blueprint image pull honcho:latest --registry ghcr.io # Prune old images rw-blueprint image prune --node infra --keep-latest 5
